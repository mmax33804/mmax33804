### ✨ Ключевые Особенности

| Фича | Описание |
| :--- | :--- |
| **🌐 Мультиязычность** | Кастомная `i18n` система (RU, RO, EN) без перезагрузки страницы. |
| **🖱 Контекстное меню** | Кастомное меню по правому клику для быстрой навигации. |
| **🌊 Плавный скролл** | Интеграция [Lenis](https://github.com/studio-freight/lenis) для идеального скроллинга. |
| **✋ Интерактивность** | Перетаскиваемые (draggable) карточки проектов. |
| **📱 Адаптивность** | Pixel-perfect верстка для мобильных и десктопных устройств. |

### 🛠 Технологический Стек

- **HTML5 & CSS3** (Flexbox, Grid, Custom Properties)
- **Vanilla JavaScript** (Никаких тяжелых фреймворков, чистый быстрый DOM)
- **Google Material Symbols** (Векторная иконографика)

### 🎨 Философия Дизайна

> *"Хороший дизайн — это как можно меньше дизайна."*

Это портфолио создано так, чтобы не отвлекать внимание, позволяя самим работам говорить за себя. Мы отказались от «прыгающих» и излишне игривых анимаций в пользу строгих, профессиональных и выверенных микроинтеракций.
